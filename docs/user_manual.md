## 1. システム概要

レーザー溶接実験の全データを一元管理するWebアプリケーションです。

**主な機能:**

- **実験プロジェクト管理**: プロジェクト単位で実験をグループ化し、独立したSQLiteファイルで管理
- **実験条件の登録**: 光学系・溶接条件・材料・シールドガス・トラジェクトリなどの条件を体系的に記録
- **実験結果の記録**: 溶接結果・OCT計測データ・観察記録を実験に紐づけて保存
- **データ分析**: チャート・グラフによる実験データの可視化と比較分析
- **レポート出力**: Markdownレポートの自動生成とダウンロード
- **OCT リモートモード**: OCT計測装置のPC（別機）から計測結果CSVパスをネットワーク経由で直接送信
- **マスタ管理**: 材料・光学部品・条件などのマスタデータの一元管理

## 2. 起動方法

### サーバー起動（管理者が行う操作）

サーバーPCのターミナルで以下を実行します:

```bash
# 仮想環境を有効化
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Mac / Linux

# サーバー起動
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

起動後、ブラウザで以下のURLにアクセスします:

| アクセス元 | URL |
|-----------|-----|
| サーバーPC自身 | `http://localhost:8000` |
| 同一ネットワーク内の別PC | `http://192.168.10.200:8000`（サーバーのIPアドレス） |

### 3-1. タブ構成

画面上部のタブで機能を切り替えます。

### 3-2. テーマカラーシステム

AppBar（上部バー）の色が現在の動作状態を示します。

| **青** `#1565c0` | オペレーター | 通常操作モード |

## 4. New Project タブ

プロジェクト単位で実験を管理するメイン操作画面です。各プロジェクトは独立したSQLiteファイルとして保存されます。

### 4-1. プロジェクト一覧

左側にプロジェクト一覧が表示されます。クリックするとそのプロジェクトの実験一覧が右側に表示されます。

**プロジェクト一覧の操作ボタン:**

| ボタン | 説明 |
|--------|------|
| `+ New Project` | 新しいプロジェクトを作成するダイアログを開く |
| 📁 (フォルダアイコン) | 既存の実験から新しいプロジェクトを作成 |
| 🗑 | プロジェクトを削除（プロジェクトDBファイルごと削除） |

### 4-2. 新しいプロジェクトを作成する

1. `+ New Project` ボタンをクリック
2. ダイアログで **プロジェクト名** を入力
3. **[作成]** をクリック → 空のプロジェクトが作成されます

### 4-3. 既存実験からプロジェクトを作成する

1. 📁 ボタンをクリック
2. プロジェクト名を選択（メインDBの実験をグループ別に表示）
3. 取り込む実験を選択 → プロジェクトが作成されます

### 4-4. プロジェクト内の実験管理

プロジェクトを選択すると、右側に実験一覧が表示されます。

**実験一覧の操作ボタン:**

| ボタン | 説明 |
|--------|------|
| `+ Add` | 新しい実験をプロジェクトに追加 |
| 📋 (コピーアイコン) | 実験をプロジェクト内でコピー、または別プロジェクトからコピー |
| ✏️ (編集アイコン) | 実験の詳細編集ダイアログを開く |
| 🗑 | 実験をプロジェクトから削除 |

**実験行をクリック** すると右側に詳細パネルが表示されます（条件ツリー・OCTボタン）。

### 4-5. フィルタリング

実験一覧上部の **フィルターバー** で条件を指定して絞り込みができます。

### 4-6. 分析タブ

実験一覧の上部にある **Analysis** タブをクリックすると、選択したプロジェクトの実験データをグラフ・チャートで可視化できます。

### 4-7. レポート出力

画面右上の **📄 Report** ボタンをクリックすると、実験データのMarkdownレポートを生成・ダウンロードできます。

## 6. Masters タブ

各種マスタデータを管理します。実験を登録する前に必要なマスタを先に作成しておく必要があります。

### 6-1. マスタエンティティ一覧

| エンティティ | 説明 |
|------------|------|
| **Materials** | 素材の物性情報（密度・熱伝導率・融点・反射率） |
| **Material States** | 材料の形状・表面状態（板厚・幅・長さ・表面仕上げ） |
| **Experiment Materials** | 実験に使用する材料の組み合わせ（Material + Material State） |
| **Laser Beams** | レーザービームプロファイル（波長・NA・M²・BPP） |
| **Laser Devices** | レーザー発振器（メーカー・型番・最大出力） |
| **FTheta** | Fθレンズ（焦点距離） |
| **Optics** | 光学系部品（役割: main / sub / OCT） |
| **DOE** | 回折光学素子 |
| **Galvano Systems** | ガルバノスキャナシステム（FTheta + Optics の組み合わせ） |
| **Line Parameters** | ラインパラメータ（速度・ピッチ） |
| **Main Trajectories** | メイントラジェクトリ（走査パターンの定義） |
| **Wobbling Parameters** | ウォブリングパラメータ |
| **Sub Trajectories** | サブトラジェクトリ |
| **Trajectory Sets** | トラジェクトリセット（Main + Sub の組み合わせ） |
| **Welding Conditions** | 溶接条件（出力・速度・フォーカスオフセット・トラジェクトリ） |
| **Shielding Conditions** | シールドガス条件（ガス種・流量・ノズル形状） |
| **Results** | 実験結果（溶接深さ・欠陥フラグ・OCT計測データパス） |
| **Observations** | 観察記録（画像・コメント・日時） |
| **Files** | 添付ファイル情報 |

### 6-2. CRUD 操作の共通手順

1. サブタブで対象エンティティを選択
2. **[+ Add]** ボタン → フォームに入力 → **[Save]** で追加
3. テーブルの行をクリック → フォームで編集 → **[Save]**
4. 行の 🗑 アイコンで削除（アドミニストレーターのみ）

### 6-3. IDフィールドの扱い

各エンティティのID（`xxx_id`）は UUID で自動生成されます。手動入力は不要です。

## 7. Import / Export タブ

データのインポート・エクスポートを行います。

### 7-1. エクスポート

| ボタン | 出力形式 | 内容 |
|--------|---------|------|
| **Export DB** | `.db` | メインSQLiteデータベースファイル全体 |

### 7-2. インポート

| ボタン | 入力形式 | 動作 |
|--------|---------|------|
| **Import DB (overwrite)** | `.db` | 全データを上書き ⚠️ |
| **Merge DB** | `.db` | 既存データを保持しながらマージ（競合時は確認ダイアログ表示） |

> ⚠️ **重要**: `Import DB (overwrite)` は既存データが**全て失われます**。  
> 実行前に必ず `Export DB` でバックアップを取得してください。

### 7-3. マージ時の競合解決

`Merge DB` を使用した際に同一IDのレコードが両方に存在する場合、差分ダイアログが表示されます。

- **Keep Mine**: 現在のDB側のデータを保持
- **Use Theirs**: インポートしたDB側のデータで上書き
- **Keep Both**: 両方のデータを保持（IDが重複している場合は新しいIDで追加）

## 10. OCT リモートモード

OCT（光干渉断層計）の計測装置が別のPC上にある場合、計測結果のCSVファイルパスをネットワーク経由でデータベースに自動登録する機能です。

### 10-1. 動作の流れ

```
[データベースPC (サーバー)]          [OCT計測PC]
        |                                  |
  ① New ProjectタブでOCT待受ボタンを押す   |
        |  (サーバーが待受状態になる)        |
        |                                  |
        |          ② oct_send.py を起動    |
        |                                  |
        |          ③ CSVパスを入力して「送信」|
        |<--------  POST /api/oct/push  ---|
        |                                  |
  ④ ResultにCSVパスが自動書き込みされる     |
  ⑤ 画面が緑のチェックマークに変わる        |
```

### 10-2. OCT 待受ボタンの操作（データベースPC側）

1. **New Project** タブを開く
2. 実験一覧から対象の実験行をクリック → 詳細パネルを展開
3. 詳細パネル右上の **📡 アイコン（WifiTetheringOff）** をクリック
4. AppBar が**紫**に変わり、OCT待受状態になります

| アイコン | 色 | 状態 |
|---------|-----|------|
| 📡（WifiTetheringOff） | グレー | 通常（待受オフ） |
| 📡（WifiTethering） | 紫 | OCT待受中 |
| ✅（CheckCircle） | 緑 | OCTデータ受信済み |

5. 待受中にもう一度アイコンをクリックすると待受を解除できます
6. OCTデータを受信するとアイコンが**緑のチェック**に変わり、スナックバーで通知されます

> **注意**: OCT待受ボタンは **New Project タブ** でのみ表示されます。Experiments タブでは表示されません。

### 10-3. Result レコードへの書き込み

OCTデータが受信されると、対象実験に紐づく `Result` レコードの以下のフィールドが更新されます:

| フィールド | 内容 |
|-----------|------|
| `oct_surface_csv_path` | 表面形状CSVのファイルパス |
| `oct_depth_csv_path` | 深さ計測CSVのファイルパス |
| `oct_result_csv_path` | 解析結果CSVのファイルパス |

## 11. OCT 送信ツール（oct_send.py）

OCT計測PCにインストールして使うPythonのGUIツールです。

### 11-1. 必要環境

```bash
pip install requests
```

Python 3.8以上が必要です。tkinterは標準ライブラリに含まれています。

### 11-2. 起動方法

OCT計測PCのターミナル（またはダブルクリック）で実行します:

```bash
python oct_send.py
```

または `tools/oct_send.py` をファイルブラウザからダブルクリック。

### 11-3. 画面の説明

```
┌─────────────────────────────────────────────────────────┐
│ サーバー URL: [http://192.168.10.200:8000] [localhost] [192.168.10.200] │
│ 待受中の実験: a6da50ce-521d-4beb-8138-9be8f40c736b      │
├─────────────────────────────────────────────────────────┤
│ Surface CSV: [C:\OCT\data\surface.csv        ] [参照...] │
│ Depth   CSV: [C:\OCT\data\depth.csv          ] [参照...] │
│ Result  CSV: [C:\OCT\data\result.csv         ] [参照...] │
│                                                           │
│          [    送信    ]    [ キャンセル ]                  │
└─────────────────────────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| **サーバー URL** | データベースサーバーのURL。手動入力も可能 |
| **localhost ボタン** | `http://localhost:8000` に切り替え（同一PC用） |
| **192.168.10.200 ボタン** | `http://192.168.10.200:8000` に切り替え（ネットワーク用） |
| **待受中の実験** | サーバーが待受中の実験IDを1秒ごとに自動表示。紫=待受中、灰=なし、赤=接続失敗 |
| **Surface / Depth / Result CSV** | 各CSVファイルのパス。`参照...` ボタンでファイルブラウザから選択可能 |
| **送信** | 確認ダイアログ後、CSVパスをサーバーに送信。成功すると自動終了 |
| **キャンセル** | ツールを終了 |

### 11-4. 使用手順

1. **データベースPCで** New Project タブ → 実験詳細 → OCT待受ボタンをクリック（紫になる）
2. **oct_send.py を起動** → 「待受中の実験」欄に実験IDが紫色で表示されるのを確認
3. サーバーURLが正しいことを確認（別PC接続の場合は `192.168.10.200` ボタンをクリック）
4. 各CSVパスをフォームに入力するか `参照...` ボタンで選択（1つ以上必須）
5. **[送信]** ボタンをクリック → 確認ダイアログで内容を確認 → **[はい]**
6. 「送信成功！」メッセージが表示され、ツールが自動的に閉じます
7. データベースPCの画面で詳細パネルのアイコンが**緑のチェック**になっていることを確認

### 11-5. エラー時の対処

| エラー | 原因 | 対処 |
|--------|------|------|
| 接続失敗 | サーバーに繋がらない | URLを確認、サーバーの起動を確認 |
| 待受中の実験なし（灰色） | 待受ボタンが押されていない | データベースPCでOCT待受ボタンを押す |
| HTTP 400 | 実験にResultが未作成 | Masters → Result にレコードを作成して実験に紐づける |
| HTTP 500 | サーバー内部エラー | バックエンドのログを確認 |

## 12. よくある操作手順

### 新しいプロジェクトで実験を記録する流れ

```
1. Masters タブ で事前にマスタデータを登録
   ├── 材料系: Materials → Material States → Experiment Materials
   ├── 光学系: Laser Beams → Laser Devices → FTheta → Optics → DOE → Galvano Systems
   ├── 溶接系: Line Parameters → Main Trajectories → Wobbling Parameters
   │           → Sub Trajectories → Trajectory Sets → Welding Conditions
   └── シールド: Shielding Conditions

2. New Project タブ → [+ New Project] でプロジェクト作成

3. プロジェクト選択 → [+ Add] で実験追加
   → 各マスタをドロップダウンから選択

4. 溶接実験実施後：
   a. Masters → Results でResultレコードを作成
   b. 実験編集ダイアログで result_id を紐づける

5. OCT計測後（別PC使用時）：
   a. 実験詳細パネル → OCT待受ボタンを押す（紫）
   b. OCT計測PCで oct_send.py を起動 → CSVを送信
```

### データを別PCに移行する

```
1. Import / Export → [Export DB] → .db ファイルをダウンロード
2. 移行先PCでサーバーを起動
3. Import / Export → [Import DB (overwrite)] → .db ファイルをアップロード
```

### プロジェクトのバックアップ

プロジェクトは `db/projects/` フォルダ内の `.db` ファイルとして保存されています。このファイルをコピーするだけでバックアップになります。

## 13. トラブルシューティング

### 画面が真っ白・エラー表示が出る

→ ブラウザのキャッシュをクリア（Ctrl+Shift+R）してページを強制リロード

### サーバーに接続できない

```
1. ターミナルで uvicorn が起動しているか確認
2. ポート 8000 がファイアウォールでブロックされていないか確認
3. URL（IPアドレス）が正しいか確認
```

### OCT待受ボタンを押しても紫にならない（404エラー）

→ バックエンドを再起動してください（uvicornがOCTルーターを認識していない可能性）

### oct_send.py で「接続失敗」が表示される

```
1. サーバーが起動しているか確認（ブラウザで http://IPアドレス:8000 を開く）
2. OCT計測PCとサーバーPCが同じネットワーク（同じルーター）に接続されているか確認
3. サーバーPCのファイアウォールでポート8000が許可されているか確認
```

### マスタデータが削除できない

→ アドミニストレーターモードに切り替えてください（右上のアイコンをクリック）

## 1. Experiments — 実験管理

### 1-1. 実験一覧の表示

- 画面上部のタブで **Experiments** を選択すると実験一覧が表示されます。
- **検索バー**に文字を入力すると `remarks` フィールドで部分一致検索できます。

| 複製 | 行の📋アイコン → 実験レコードと条件データが複製されます（Result / Observation / File は除く） |

## 2. Masters — マスタデータ管理

マスタタブ内はサブタブで各エンティティに切り替えます。

### 主なマスタエンティティ

| エンティティ | 説明 |
|------------|------|
| Materials | 材料の物性情報（密度・熱伝導率・反射率） |
| Material States | 材料の形状・表面状態（板厚・幅・長さ） |
| Laser Beams | ビームプロファイル（波長・NA・M²・BPP） |
| Laser Devices | レーザー発振器（メーカー・型番） |
| FTheta | Fθレンズ（焦点距離） |
| Optics | 光学系（役割: main / sub / OCT） |
| DOE | 回折光学素子 |
| Galvano Systems | ガルバノスキャナシステム（FTheta + Optics の組み合わせ） |
| Welding Conditions | 溶接条件（出力・速度・フォーカスオフセット） |
| Trajectory Sets | トラジェクトリセット（Main + Sub の組み合わせ） |
| Shielding Conditions | シールドガス条件（ガス種・流量・ノズル） |
| Results | 実験結果（OCT深さ・欠陥フラグ） |
| Observations | 観察記録（コメント・日時） |

### CRUD 操作の共通手順

1. 対象のサブタブを選択
2. **[+ Add]** → フォームに入力 → **[Save]**
3. 行をクリックして選択 → フォームで編集 → **[Save]**
4. 行の 🗑 アイコンで削除

## 4. Settings — 設定

### 4-1. Columns タブ（カラム定義管理）

- 各テーブルのカラム定義（表示名・データ型・単位・選択肢）を管理します。
- グループタブ（EXPERIMENT / GALVANO_SYSTEM など）でテーブルを切り替えます。
- **is_id = "id"** を指定すると、UUID 型の ID カラムを自動生成します。
  - カラム名が `{テーブル名}_id` の場合 → **主キー (PK)** として登録
  - それ以外の場合 → **外部キー (FK)** として登録し、参照先テーブルの PK も自動生成

### 4-2. Colors タブ（テーマ設定）

- **Dark Mode** トグルで画面のテーマを切り替えます（ライト／ダーク）。
- 設定はデータベースに保存され、次回起動時も維持されます。

## 6. よくある操作手順

### 新しい実験を登録する流れ

```
1. Masters タブ → 必要なマスタデータを事前登録
   （材料 → 材料状態 → 実験材料）
   （レーザービーム → レーザーデバイス → 光学系 → FTheta → ガルバノシステム）
   （ラインパラメータ → メイントラジェクトリ → ウォブリングパラメータ → サブトラジェクトリ → トラジェクトリセット → 溶接条件）
   （シールド条件）

2. Experiments タブ → [+ New]
   → 各マスタを選択して実験レコードを作成

3. 実験後 → Results / Observations を Masters タブで作成
   → 実験レコードを編集して result_id / observation_id を紐づけ
```

### データをバックアップしてから別 PC に移行する

```
1. Import / Export → [Export DB] → .db ファイルをダウンロード
2. 移行先 PC でアプリを起動
3. Import / Export → [Import DB (overwrite)] → .db ファイルをアップロード
```
