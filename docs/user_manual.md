# User Manual — Laser Experiment Database

## 概要

このシステムはレーザー溶接実験のデータを一元管理するWebアプリケーションです。  
実験条件（光学系・溶接条件・材料・シールドガス）と実験結果を登録・検索・エクスポートできます。

---

## 画面構成

| タブ | 説明 |
|------|------|
| **Experiments** | 実験レコードの一覧・作成・編集・削除・複製 |
| **Masters** | 各種マスタデータ（材料・光学系・溶接条件など）の管理 |
| **Import / Export** | データの入出力（JSON / CSV / SQLite） |
| **Settings** | カラム定義・テーマの設定 |
| **Documents** | システムドキュメント（本マニュアル・ER図・APIリファレンスなど） |

---

## 1. Experiments — 実験管理

### 1-1. 実験一覧の表示

- 画面上部のタブで **Experiments** を選択すると実験一覧が表示されます。
- **検索バー**に文字を入力すると `remarks` フィールドで部分一致検索できます。
- 列ヘッダをクリックすると昇順／降順でソートできます。
- **[+ New]** ボタンで新規実験フォームを開きます。

### 1-2. 実験の新規作成

1. **[+ New]** をクリック
2. 各フィールドを入力（マスタ参照フィールドはドロップダウンから選択）
3. **[Save]** で保存 → 一覧に追加されます
4. **[Save & Next]** で保存後すぐに次の実験フォームを開きます

### 1-3. 実験の編集・削除・複製

| 操作 | 方法 |
|------|------|
| 編集 | 行をクリック → 右パネルのフォームを編集 → **[Save]** |
| 削除 | 行の 🗑 アイコン → 確認ダイアログで **[Delete]** |
| 複製 | 行の📋アイコン → 実験レコードと条件データが複製されます（Result / Observation / File は除く） |

## 2. Masters — マスタデータ管理

マスタタブ内はサブタブで各エンティティに切り替えます。

### 主なマスタエンティティ

| エンティティ | 説明 |
|------------|------|
| Materials | 材料の物性情報（密度・熱伝導率・反射率） |
| Material States | 材料の形状・表面状態（板厚・幅・長さ） |
| Laser Beams | ビームプロファイル（波長・NA・M²・BPP） |
| Laser Devices | レーザー発振器（メーカー・型番） |
| FTheta | Fθレンズ（焦点距離） |
| Optics | 光学系（役割: main / sub / OCT） |
| DOE | 回折光学素子 |
| Galvano Systems | ガルバノスキャナシステム（FTheta + Optics の組み合わせ） |
| Welding Conditions | 溶接条件（出力・速度・フォーカスオフセット） |
| Trajectory Sets | トラジェクトリセット（Main + Sub の組み合わせ） |
| Shielding Conditions | シールドガス条件（ガス種・流量・ノズル） |
| Results | 実験結果（OCT深さ・欠陥フラグ） |
| Observations | 観察記録（コメント・日時） |

### CRUD 操作の共通手順

1. 対象のサブタブを選択
2. **[+ Add]** → フォームに入力 → **[Save]**
3. 行をクリックして選択 → フォームで編集 → **[Save]**
4. 行の 🗑 アイコンで削除

## 3. Import / Export — データ入出力

### エクスポート

| ボタン | 出力形式 | 内容 |
|--------|---------|------|
| Export DB | `.db` | SQLite データベースファイル |

### インポート

| ボタン | 入力形式 | 動作 |
|--------|---------|------|
| Import DB (overwrite) | `.db` | 全データを上書き ⚠️ |
| Merge DB | `.db` | 既存データを保持しながらマージ |

> **注意**: Import DB (overwrite) は既存データがすべて失われます。事前にエクスポートしてバックアップを取ってください。

## 4. Settings — 設定

### 4-1. Columns タブ（カラム定義管理）

- 各テーブルのカラム定義（表示名・データ型・単位・選択肢）を管理します。
- グループタブ（EXPERIMENT / GALVANO_SYSTEM など）でテーブルを切り替えます。
- **is_id = "id"** を指定すると、UUID 型の ID カラムを自動生成します。
  - カラム名が `{テーブル名}_id` の場合 → **主キー (PK)** として登録
  - それ以外の場合 → **外部キー (FK)** として登録し、参照先テーブルの PK も自動生成

### 4-2. Colors タブ（テーマ設定）

- **Dark Mode** トグルで画面のテーマを切り替えます（ライト／ダーク）。
- 設定はデータベースに保存され、次回起動時も維持されます。

## 6. よくある操作手順

### 新しい実験を登録する流れ

```
1. Masters タブ → 必要なマスタデータを事前登録
   （材料 → 材料状態 → 実験材料）
   （レーザービーム → レーザーデバイス → 光学系 → FTheta → ガルバノシステム）
   （ラインパラメータ → メイントラジェクトリ → ウォブリングパラメータ → サブトラジェクトリ → トラジェクトリセット → 溶接条件）
   （シールド条件）

2. Experiments タブ → [+ New]
   → 各マスタを選択して実験レコードを作成

3. 実験後 → Results / Observations を Masters タブで作成
   → 実験レコードを編集して result_id / observation_id を紐づけ
```

### データをバックアップしてから別 PC に移行する

```
1. Import / Export → [Export DB] → .db ファイルをダウンロード
2. 移行先 PC でアプリを起動
3. Import / Export → [Import DB (overwrite)] → .db ファイルをアップロード
```
