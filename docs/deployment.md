# Laser Experiment Database — 展開手順

## 必要なもの

| | ソースPC（開発者） | ターゲットPC（配布先） |
|---|---|---|
| Python 3.13 | ✅ | ✅ 必須 |
| Node.js | ✅ | ❌ 不要 |
| Docker | ❌ 不要 | ❌ 不要 |

---

## ソースPC での作業（配布前に1回だけ）

### 1. フロントエンドをビルドする

PowerShell から以下を実行：

```powershell
cd frontend
npm run build
```

または `build.ps1` を実行する。

完了すると `frontend/dist/` フォルダが生成される。

### 2. 配布ファイルをZIPにまとめる

推奨: `package_deploy.ps1` を実行する。

- 必要な配布物のみを自動収集して `release/` にZIPを作成
- 生成例: `release/database_deploy_YYYYMMDD_HHMMSS.zip`

手動で作る場合は、以下のフォルダ・ファイルを選択してZIP圧縮する：

```
database/
  ├── backend/
  ├── frontend/
  │     └── dist/          ← ビルド済みファイル（必須）
  ├── db/                  ← データごと渡す場合はそのまま、新規は空でOK
  ├── setup.ps1
  ├── deploy.ps1
  └── pyproject.toml
```

> `.venv/` と `frontend/node_modules/` は容量が大きいので含めない。

## ターゲットPC での作業

### 1. Python 3.13 をインストール

https://www.python.org/downloads/

> インストール時に **「Add Python to PATH」にチェック** を入れること。

### 2. ZIPを展開する

任意のフォルダに展開する（例: `C:\tools\database\`）。

### 3. セットアップを実行する（初回のみ）

PowerShell で `setup.ps1` を実行する。

- Python仮想環境 (`.venv`) を自動作成
- 必要なパッケージを自動インストール

### 4. アプリを起動する

PowerShell で `deploy.ps1` を実行する。

ブラウザが自動で開き、`http://localhost:8000` でアプリが使える。

### 5. 終了する

ターミナルウィンドウを閉じる、または `Ctrl+C` を押す。

## 既存システムが入っているPCでの置き換え手順

### 目的

- 既存データを保持したまま、新しい版へ安全に入れ替える。

### 1. 既存システムを停止

- 起動中のアプリを閉じる。
- 必要ならタスクマネージャーで Python / uvicorn が残っていないことを確認する。

### 2. 旧版をバックアップ（必須）

- 旧フォルダ全体を日付付きで退避する。
  - 例: database_20260603_backup
- 最低限、以下は必ず退避する。
  - db/（実データ）
  - .env（存在する場合）

### 3. 新版を展開

- 新しい配布ZIPを別フォルダに展開する。
- 上書き展開より、別フォルダ展開のほうがロールバックしやすい。

### 4. データを引き継ぐ

- 旧版バックアップから db/ を新版フォルダへコピーする。
- .env を使っている場合は同様にコピーする。

### 5. セットアップを再実行

- [setup.ps1](setup.ps1) を実行する。
- 理由: 依存パッケージ差分や Python 環境差分を吸収するため。

### 6. 起動確認

- [deploy.ps1](deploy.ps1) を実行する。
- ブラウザでトップ画面表示、既存データ表示、主要操作を確認する。

### 7. 問題が出た場合のロールバック

- 新版フォルダを停止する。
- バックアップしておいた旧版フォルダへ戻して起動する。
- 復旧後に、エラーログと手順差分を確認して再実施する。

## トラブルシューティング

| エラー | 対処 |
|---|---|
| `setup.ps1` でpipが失敗する | 社内プロキシの設定が必要な場合あり。IT部門に確認 |
| `frontend\dist\index.html が見つからない` | ソースPCで `build.ps1` を実行してから再配布 |
| ポート8000が使用中 | 他のアプリを停止するか、`deploy.ps1` 内の `--port 8000` を変更 |

---

## アップデート時

ソースPCでコードを修正したら：

1. `build.ps1` を再実行（フロントエンドを変更した場合）
2. `backend/` と `frontend/dist/` を上書きコピー
3. ターゲットPCで `deploy.ps1` を再起動
